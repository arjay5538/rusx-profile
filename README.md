# RUSX. | Personal Profile

A mobile-first personal landing page designed in Framer and recreated with HTML, CSS, and vanilla JavaScript. It brings my profile and social links together on a single page.

## Features

- Black-and-white portrait with dark fades and lavender accents
- Social buttons for Instagram, Facebook, TikTok, X, and Gmail
- An info button that opens a profile dialog
- A responsive layout with no dependencies or build step

## Run locally

Clone or download the repository, then open `index.html` in your browser.

## Add your social links

Open `profile.js` and fill in the `socialLinks` object with your profile URLs. For Gmail, use `mailto:your@email.com`. Buttons stay inactive until their destinations are set.
